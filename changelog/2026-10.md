# October 2026

## 2026-10-13

### Added
- **Customer seat add-ons** — customers can buy additional license seats from the
  buyer portal; checkout, discount, PayPal, and Stripe flows honor extra seats.
  See [`docs/guides/licenses.md`](../docs/guides/licenses.md).

### Changed
- Seat picker and seat checkout UI polish.
- Analytics breakdown and overview card tweaks.

## 2026-10-09

### Added
- **Email check** — send a test email from **Dashboard → Setup** to verify
  Cloudflare Email Service config.
- **Resend order confirmation** — new action in the orders menu.

### Fixed
- Transactional emails now use the recipient's time zone.

## 2026-10-08

### Added
- **Extra seats** — merchants can sell additional license seats per product,
  with a configurable seat label. Editor in the product form, picker at checkout.
  Migrations `0029_product_extra_seats`, `0030_extra_seat_label`.
- **User time zones** — per-user time zone in **Settings → General**; dates in
  the dashboard, customer portal, analytics, and notification emails render in
  that zone. Migration `0031_user_timezone`.
- License activation API and docs updated for seats and time zone.

## 2026-10-07

### Added
- Option to control category visibility on the storefront.

### Changed
- Mobile UI, tooltip, and general dashboard polish.
