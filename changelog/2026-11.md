# November 2026

## 2026-11-17

### Added
- **Stripe Tax** — new **Dashboard → Settings → Tax** page to enable automatic
  tax calculation on Stripe checkout sessions. Per-store setting. Migration `0033_stripe_tax`.

## 2026-11-11

### Added
- **MCP server** — stateless endpoint at `POST /api/mcp` exposing tools for
  products, categories, orders, and customer / discount / license / subscriber
  records. Tools are filtered by the calling API key's permissions.
- **Scoped API keys** — per-resource read / write / delete scopes, with a
  permissions picker in the API keys UI. Scopes are enforced on `/api/v1`
  endpoints. Existing keys keep read-only access to products, orders, and
  customers. Migration `0032_api_key_scopes`. See
  [`docs/guides/api-keys.md`](../docs/guides/api-keys.md).
- **SEPay payments** — connect SEPay in **Settings → Payments**, hosted checkout
  button, webhook handler, and a pending-confirmation page on checkout success.
  New env vars in `.env.example`; see
  [`docs/guides/payment-setup.md`](../docs/guides/payment-setup.md).

### Changed
- Dashboard overview stats and database queries reworked for faster loading.
- Icon set updated across dashboard, customer portal, checkout, and setup screens.
- Added `yarn.lock` and `.yarnrc.yml` for Yarn installs.

### Fixed
- Minor layout fix in the customer profile details view.
