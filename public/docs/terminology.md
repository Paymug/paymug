# Terminology

- **Seller:** the person who owns the store and connects payment accounts.
- **Store:** the seller's public storefront and settings.
- **Customer:** a buyer who can use the customer portal.
- **Product:** an item or subscription a seller offers.
- **Order:** the recorded result of a purchase.
- **Delivery:** a file, license, redirect, or GitHub access granted after payment.
- **Test mode:** a safe environment for test products and sandbox payments.
- **Live mode:** the environment for real products and real payments.
- **API key:** a secret that lets an integration call the public merchant API.
- **License:** a key that can enable a product or Paymug Pro plan.
- **Activation:** linking a license to one installation identity.
- **Webhook:** an HTTP message sent to an integration after an event.
- **Delivery ID:** the unique ID of one webhook delivery; use it for deduplication.
- **Pro feature:** a feature enabled by an active Pro license.

If a user uses a different term, repeat their term and map it to the closest
Paymug term instead of assuming a technical meaning.
