# Getting started

## What you need

- A Paymug installation URL or a local installation.
- An email address for your seller account.
- Test payment credentials for your first sale.

## First test sale

1. Create an account and store.
2. Select test mode.
3. Connect PayPal sandbox or Stripe test mode.
4. Create and publish a test product.
5. Open the product checkout link.
6. Complete a test payment.
7. Check the paid order and delivery.

Do not use live payment credentials until the full test flow works.
