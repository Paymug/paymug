# Products

Create a product for a digital file, license, private GitHub access, or
subscription.

1. Open Dashboard → Products.
2. Create a product and add its name, description, and price.
3. Choose the delivery method.
4. Add the file, license settings, or GitHub repository when needed.
5. Save and publish the product.
6. Copy the checkout link and test it.

Keep a product unpublished while its price, payment, and delivery settings are
being tested.
