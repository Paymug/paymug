# Paymug API

Use the public API to read products, orders, and customers. Use the license API
to activate, validate, or deactivate a Paymug Pro installation.

- [Quickstart](quickstart.md)
- [License activation](license-activation.md)
- [Outbound webhooks](outbound-webhooks.md)
- [OpenAPI specification](openapi.yaml)

Only endpoints documented here are supported integration contracts. Dashboard
transport endpoints may change.
