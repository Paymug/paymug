# Customer help

Use the customer portal to sign in, view purchases, download files, use license
keys, manage account details, and change email preferences.

If a purchase is missing, confirm the email address, store URL, payment status,
and test/live environment. Contact the store owner for payment or access help.

Read the [AI customer workflow guide](../ai/customer-workflows.md) for a short
support checklist.
