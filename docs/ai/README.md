# AI documentation map

The public entry point is [AGENTS.md](/AGENTS.md). These files help an AI agent
use Paymug and its APIs. They are not a guide to the source code.

| Need | Read |
| --- | --- |
| Learn what Paymug does | [Product overview](/docs/product-overview.md) |
| Prepare a safe test store | [Setup](/docs/setup-and-test-environment.md) |
| Use a feature | [Feature recipes](/docs/feature-recipes.md) |
| Activate Pro | [License activation](/docs/license-activation.md) |
| Call the public API | [API reference](/docs/api-reference.md) and [API workflows](/docs/api-workflows.md) |
| Test a purchase | [Payment and checkout testing](/docs/payment-and-checkout-testing.md) |
| Send or receive webhooks | [Webhook workflows](/docs/webhook-workflows.md) |
| Fix a problem | [Troubleshooting](/docs/troubleshooting.md) |

The source files are `public/AGENTS.md` and `public/docs/*.md`. On the site,
`/AGENTS.md` is the entry point and the related guides are under `/docs/`.
